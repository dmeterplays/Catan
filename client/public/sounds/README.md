# Audio sources and licenses

- `dice.mp3`: compressed copy of the user-provided "Dice_Roll" recording by schoman3 (Freesound), distributed via Pixabay under the Pixabay Content License: https://pixabay.com/sound-effects/household-dice-roll-96878/ . The original user-supplied recording was resampled to mono and compressed for web delivery.
- Ship departure bell: the game streams the "Hand Bell Single Bell Strike 42" recording from SFXMint, under CC0 1.0: https://sfxmint.com/sounds/instrument-bell-42 . The game plays it twice at departure.
- `seven.wav`, `milestone.wav` and `victory.wav`: original synthesized effects created specifically for this project. They do not incorporate third-party musical samples or recognizable melodies.

The sound effects are triggered by game events from the multiplayer server. Browser playback remains subject to browser audio-unlock policies.
